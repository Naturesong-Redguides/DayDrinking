# DayDrinking

Alcohol Tolerance training script for Macroquest.

## Description

Automatically has your toon drink alchohol at a configurable rate and level of drunkenness.

## Additional Notes

Use of macroquest on Everquest Live and test is a breach of the games EULA.

### Dependencies

* Macroquest

### Installing

Place the script in the macroquest\Release\lua\DayDrinking folder

### Executing program

* Run `/lua run DayDrinking`.

## Help

* There is no help.
* Ingame commands are listed via the command `/daydrinking` once the script is running.
